# 贡献者

Requests 是一个由社区驱动的项目，它的成功离不开其创建者的奉献以及众多贡献者的宝贵付出。本页面旨在感谢所有帮助该库发展至今的人。

## 创建者

Requests 由 Kenneth Reitz 创建。
