# User Guide

Welcome to the Requests User Guide! This guide provides a deep dive into the core features of the library, helping you master common workflows and handle various web interaction scenarios. We assume you've already completed the installation and your first request as outlined in the [Getting Started](./getting-started.md) guide.

This guide is structured to walk you through the lifecycle of an HTTP request, from creation to response handling and beyond. Each section focuses on a specific aspect of the library, complete with practical, code-first examples.

<x-cards>
  <x-card data-title="Making a Request" data-icon="lucide:send" data-href="/user-guide/making-a-request" data-cta="Learn More">
    Learn how to use various HTTP methods like GET, POST, and PUT, and how to pass URL parameters, headers, and request bodies.
  </x-card>
  <x-card data-title="Handling Responses" data-icon="lucide:download" data-href="/user-guide/handling-responses" data-cta="Learn More">
    Understand how to access response content in different formats (text, JSON, binary), check status codes, and read response headers.
  </x-card>
  <x-card data-title="Session Objects" data-icon="lucide:orbit" data-href="/user-guide/session-objects" data-cta="Learn More">
    Utilize Session objects to persist parameters, cookies, and headers across multiple requests for improved performance and state management.
  </x-card>
  <x-card data-title="Authentication" data-icon="lucide:key-round" data-href="/user-guide/authentication" data-cta="Learn More">
    Implement various authentication schemes, including Basic and Digest Auth, to secure your requests and access protected resources.
  </x-card>
  <x-card data-title="Error Handling" data-icon="lucide:shield-alert" data-href="/user-guide/error-handling" data-cta="Learn More">
    Learn to anticipate and handle potential request errors, such as connection issues, timeouts, and non-successful HTTP statuses.
  </x-card>
</x-cards>

## Next Steps

After exploring these sections, you'll have a solid foundation for using Requests in your projects. When you're ready to tackle more complex scenarios, dive into our [Advanced Usage](./advanced-usage.md) guide to explore features like custom timeouts, proxies, and SSL certificate verification.
