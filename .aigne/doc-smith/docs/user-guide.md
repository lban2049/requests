# User Guide

Welcome to the Requests User Guide. This section is designed to help you get the most out of the library by exploring its core functionalities through practical, code-first examples. Whether you're sending your first request or managing complex sessions, these guides will walk you through the most common use cases.

Each guide is self-contained, so feel free to jump to the topic that is most relevant to your needs.

<x-cards data-columns="2">
  <x-card data-title="Making a Request" data-icon="lucide:send-horizontal" data-href="/user-guide/making-a-request">
    Learn how to use various HTTP methods like GET, POST, PUT, and how to pass URL parameters, headers, and request bodies.
  </x-card>
  <x-card data-title="Handling Responses" data-icon="lucide:arrow-down-left-square" data-href="/user-guide/handling-responses">
    Understand how to access response content (text, JSON, binary), check status codes, and read response headers.
  </x-card>
  <x-card data-title="Session Objects" data-icon="lucide:orbit" data-href="/user-guide/session-objects">
    Utilize Session objects to persist parameters, cookies, and headers across multiple requests for improved performance and state management.
  </x-card>
  <x-card data-title="Authentication" data-icon="lucide:key-round" data-href="/user-guide/authentication">
    Implement various authentication schemes, including Basic and Digest Auth, to secure your requests.
  </x-card>
  <x-card data-title="Error Handling" data-icon="lucide:shield-alert" data-href="/user-guide/error-handling">
    Learn to anticipate and handle potential request errors, such as connection issues, timeouts, and bad HTTP statuses.
  </x-card>
</x-cards>
