# 许可证

Requests 是一款开源软件，以宽松的许可证向所有人提供。本页概述了该库的发布条款。

## Apache 2.0 许可证

Requests 库采用 **Apache 许可证 2.0 版本**（简称“许可证”）授权。这是一个 OSI 批准的许可证，意味着您可以自由地在自己的项目（包括商业应用）中使用、修改和分发该软件。

您可以在此处查看完整的许可证文本：
- **Apache 2.0 许可证官方文本：** [http://www.apache.org/licenses/LICENSE-2.0](http://www.apache.org/licenses/LICENSE-2.0)
- **代码库中的许可证文件：** 许可证的副本包含在源代码发行版中，并可在 [GitHub](https://github.com/psf/requests/blob/main/LICENSE) 上查看。

### 关键条款摘要

为了帮助您快速了解您的权利和义务，以下是 Apache 2.0 许可证的摘要。这并非法律建议，仅供参考。

| 类别 | 摘要 |
|---|---|
| **权限** | 您被授予出于任何目的（商业、个人等）使用、分发和修改该软件的权利。 |
| **条件** | 您在分发时必须提供 Apache 2.0 许可证的副本。如果您修改了文件，必须包含一份关于您所做更改的声明。所有原始的版权、专利、商标和归属声明都必须保留。 |
| **限制**| 该软件“按原样”提供，不附带任何形式的保证。该许可证不授予您使用项目贡献者商标的任何权利。 |
