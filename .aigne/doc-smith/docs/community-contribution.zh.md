# 社区与贡献

Requests 是使用最广泛的 Python 软件包之一，每周下载量约为 3000 万次，并有超过 1,000,000 个存储库依赖它。这个强大的社区是其贡献者共同努力的证明。本节提供有关项目起源、维护者以及如何参与 Requests 项目并为其做出贡献的信息。

## 项目起源与领导

Requests 最初由 Kenneth Reitz 创建并精心开发。

该项目由被称为“水晶守护者”的专职人员维护。当前的守护者是 Nate Prewitt 和 Seth M. Larson。

担任过守护者的前重要贡献者包括：

*   Kenneth Reitz
*   Cory Benfield
*   Ian Cordasco

![Kenneth Reitz](https://raw.githubusercontent.com/psf/requests/main/ext/kr.png)

## 补丁和建议

Requests 的发展极大地受益于社区的贡献，其中包括来自众多个人的大量补丁和建议。项目的增长和稳定性是这些努力的直接成果。

您可以在项目的 GitHub 页面上查看所有贡献者的完整列表：

[![Contributors](https://img.shields.io/github/contributors/psf/requests.svg)](https://github.com/psf/requests/graphs/contributors)

参与社区并为项目做出贡献可以包括报告问题、提出改进建议或提交代码更改。您的参与有助于确保 Requests 仍然是一个可靠且强大的 HTTP 库。

## 参与社区

我们鼓励您参与 Requests 社区。无论是报告错误、建议新功能还是贡献代码，您的参与对于项目的持续成功和发展都至关重要。
